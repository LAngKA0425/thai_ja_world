# apps/web

사용자용 Next.js 웹 애플리케이션

## 페이지 구조
- `(auth)` — 로그인, 회원가입
- `(main)` — 광장, 미니홈피, 상점, 친구, 메시지, 설정
- `(marketing)` — 마케팅 랜딩

## 피처 도메인
plaza, minihome, shop, friendship, message, authentication, avatar, guestbook, miniroom, points, quests, notifications, broadcast, profile, inventory, payment, membership, presence

## 공통 컴포넌트
- `components/layout` — 레이아웃 셸
- `components/navigation` — 네비게이션 바, 탭
- `components/feedback` — 토스트, 스피너, 에러 바운더리
